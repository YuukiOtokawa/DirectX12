# AI向け資料

このフォルダは、AIがプロジェクトを調べる際のルールと設計資料の置き場。
最初に `AGENTS.md` を読み、残りは対象の作業に応じて読む。

| 資料 | 内容 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | 閲覧、編集、Git、検証、報告のルール |
| [PROJECT.md](PROJECT.md) | 現在の構成と実装を調べる入口 |
| [VALIDATION.md](VALIDATION.md) | ビルド・動作確認の手順と判定基準 |
| [仕様書テンプレート](specs/TEMPLATE.md) | 機能ごとの仕様を書くための雛形 |

## 既存資料

- [README.md](../README.md): プロジェクトの概要。
- [TODO.md](../TODO.md): やりたいこと・進捗の記録。
- [Refactoring.md](../Refactoring.md): リファクタリングの記録と計画。
- [Bloom.md](../Bloom.md): Bloomに関する既存資料。

既存資料は移動・複製せず参照する。計画や過去の完了記録は、現在の動作を保証するものではない。
AI向けの作業ルールと設計資料は `.agent/` に集約する。

## 仕様書の追加方法

追加を依頼されたら `specs/TEMPLATE.md` を元に `specs/<機能名>.md` を作る。
状態を「提案」「合意済み」「実装確認済み」に分け、実装確認済みでも動作検証の有無を別に記載する。
仕様とコードが食い違った場合は、現状・期待する挙動・差異を示し、どちらかを無断で書き換えない。
