# 検証手順

検証実行を依頼されたときに使用する。調査のみの場合は実行せず、必要な確認として報告する。

## ビルド

1. 対象 `.vcxproj` の `PlatformToolset`、構成、依存プロジェクトを確認する。
2. インストール済みVisual Studioを調べ、対応する `vcvars64.bat` または `VsDevCmd.bat` を明示的に呼び出す。実行するMSBuildと同じプロセスに環境設定を引き継ぐ。
3. 初期化済みの開発者コマンド環境で、リポジトリルートから次を実行する。

```text
msbuild DirectX12.vcxproj /t:Build /p:Configuration=Debug /p:Platform=x64 /m
```

これはコマンド例であり、この資料作成時に実行した結果ではない。
構成を変更した場合は、その構成を明記する。ビルド失敗時にツールセットやプロジェクトを無断で変更しない。

## 動作確認

- 実行ファイル、構成、作業ディレクトリを記録する。相対パスで参照するアセット・シェーダーがあるため、通常はリポジトリルートを作業ディレクトリとする。
- 対象シェーダーを使う処理を実行し、コンパイルエラーを確認する。C++ビルド成功だけではHLSLの検証にならない。
- 描画変更では対象のGame View / Scene View、マテリアル、ライト、カメラ条件で表示を確認する。
- リソース管理変更では、変更に関係するリサイズ、差し替え、削除、終了操作を確認する。
- 調査範囲に応じてデバッグ出力やD3D12の診断メッセージを確認する。

## 報告例

```text
静的確認: 対象ファイル・確認内容
C++ビルド: 未実施 / 成功 / 失敗（構成・実行コマンド）
実行時シェーダー: 未実施 / 確認した対象と結果
画面・操作確認: 未実施 / 条件と結果
残る確認: ユーザーが再現できる手順
```
